# Contribuindo para o Drive2HD

Obrigado por contribuir!

## Fluxo recomendado

1. Abra uma issue descrevendo bug/melhoria.
2. Faça alterações pequenas e focadas.
3. Não inclua credenciais, tokens ou dados pessoais em commits.
4. Atualize documentação quando necessário.
5. Abra um Pull Request com contexto e passos de validação.

## Checklist antes do PR

- [ ] Mudança limitada ao escopo do problema
- [ ] Documentação atualizada (quando aplicável)
- [ ] Sem segredos/credenciais no diff
- [ ] Testes/checks relevantes executados (quando aplicável)
